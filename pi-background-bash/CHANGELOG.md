# 更新日志

## 0.2.3

- 原生 widget 只显示正在运行的后台任务；最后一个后台任务结束后立即隐藏，无运行任务时命令/快捷键不强制显示。前台与历史任务仍可通过 `bash_jobs` 查询，完成通知和唤醒逻辑不变。

## 0.2.2

- npm 包名使用 `@librola33/pi-background-bash`，避免与其他维护者的同名包冲突；目录、工具、命令、Web 界面 ID 和事件频道保持不变。
- 默认前台等待 180 秒，可配置等待时间与自动转后台开关；自动超时移交后给出实际任务 ID 的停止方法。
- 唤醒提示保持隐藏；完成记录已经进入正常模型响应后取消重复唤醒，未读及请求期间才完成的任务仍保留唤醒。
- 原生任务列表改用 widget：CLI 原位展开／收起，原版 Pi Web 可通过自带底栏展示完整列表；移除旧 CLI 点击弹层，既有扩展版 Web 适配独立保留。
- 完成事实与唤醒分离，在安全边界保存完成记录；Stop 后不丢记录、不意外重启模型。
- 移除工具与完成输出的重复任务入口。
- 明确主动后台、手动移交与前台等待超时的区别，超时文案说明秒数和命令未被终止。

## 0.2.1

- 顶部后台任务按钮显示运行数量，并只读自动刷新。

## 0.2.0

- 增加 Pi Web 顶部任务下拉框和受限公共查询／操作协议。
