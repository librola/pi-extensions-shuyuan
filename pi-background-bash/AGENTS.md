# pi-background-bash

独立的 Pi 扩展，不修改 Pi Web 或 Pi 的私有方法。

- 使用公开的 `createBashToolDefinition` / `createLocalBashOperations`，复用宿主的 shell、环境注入、输出格式和进程树终止。
- `timeout` 是 TUI/RPC 的前台等待期限，默认 180 秒；单次参数优先于 Pi 有效设置中的 `backgroundBash.defaultTimeoutSeconds`，配置优先于内置默认值，不自动改写设置文件。`backgroundBash.autoBackground` 默认 true；false 仅禁用自动移交、继续前台等待，不禁用显式后台或手动移交。`hard_timeout` 才终止命令。后台任务脱离发起工具调用的 AbortSignal。返回文案按实际移交原因区分主动后台、等待超时和手动移交；超时注明秒数与命令未被终止；自动移交后仍运行时给出实际任务 ID 的停止调用，说明 Stop 主 agent 不会停止后台任务。不能根据工具参数猜测手动移交原因。
- 完成事实用 `pi.sendMessage(..., { triggerTurn: false })` 在安全边界保存；隐藏的唤醒提示与可见完成事实分离。通过公开 `context_with_system` 取请求中的本扩展完成记录快照，只有 assistant 的 `message_end` 为 stop/toolUse/length 才取消这些任务的待唤醒；仅写入历史、准备请求或失败响应不算已读，不清除请求期间才完成的任务。仍未确认的结果等自然 `agent_settled` 唤醒；列表最多 20 个任务，截尾另保留布尔标记、保守补一次唤醒，不能因最近任务已读漏掉较早结果。Stop 后只保存事实、不重启模型。不得伪造用户输入，禁止模型轮询等待。
- 所有任务按会话隔离；关闭、reload、切换会话和树导航必须清理任务，不能向新会话发送旧任务的通知。
- 日志回收只删除自有临时日志，不改会话文件。运行与在途保护优先；会话七天无真实活动可过期，未读结果七天只解除未读保护，活动上下文引用仍保留。回收账本独立于二十条任务列表和 Stop 会清空的唤醒队列；原文指纹、传输观察与正常响应共同确认已读。有效投影包含摘要、系统提示和新追加消息；压缩/编辑使旧无引用证明失效。关闭标记在 JobManager 完全结束写入后保存。旧无索引日志须七天以上且上下文、文件版本及自有进程 fd 检查完整；未知、损坏和超预算先保留。测试预加载隔离临时根，成功退出回收自产日志，失败留证。
- 不启动工厂期的计时器或进程，不修改全局 Pi 配置，不引入运行时依赖。
- 注释、文档和提交信息使用中文。
- 原生任务信息使用同一个 setWidget 接口兼容 CLI 和标准 RPC：CLI 摘要可用 Ctrl+Shift+J 原位展开/收起，/bash-jobs 原位展开；不创建额外鼠标点击入口或 custom 弹层，不接管 footer、不移动编辑器焦点。Esc 只收起，其他弹层拥有焦点时不拦截按键。widget 只显示正在运行的后台任务；前台和终态记录不显示，最后一个后台任务结束后立即移除 widget，无任务时命令/快捷键也不能强制显示。不删除底层任务记录或改变完成通知/唤醒。隐藏后迟到的旧工厂不能恢复 widget 或覆盖下一批任务。RPC 必须提供完整的运行中后台任务列表，让原版 Pi Web 自带底栏折叠，不依赖 TUI 交互回调。窄屏和命令控制字符必须安全处理；后台任务运行期间更新耗时，全部后台任务结束/会话清理释放计时器；会话清理释放输入监听。UI 清理失败不能阻止旧进程终止。不得修改既有扩展版 Web 的浏览器文件、顶部入口、协议或 manifest 来实现这个原生兼容。
- Web 代码通过 `piWeb` 和独立公共事件协议对接，只注册顶部下拉入口，不占侧栏或修改宿主核心。仅使用宿主 React，前后端资源必须分开声明。工具和完成输出不添加重复的弹框按钮，保留原始视图及其原生操作。
- 顶部数量自动只读查询当前已绑定实例，只统计 `background && running`；实例缺失时不显示假 0。其余详细状态/输出查询需用户明确操作，写操作必须确认，不接受任意命令或路径。不能把历史 `running` 当作已恢复的活动进程。
- 下拉关闭时清理详情资源，顶部数量继续更新；切换、禁用时清理原视图的全部资源；不能因此取消原生任务。Esc 只关闭下拉，不误停主 agent。
- 修改后运行 `npm run check`；Web 改动额外运行指定 fork 的 `npm run test:web`。测试使用隔离配置和本地 HTTP，不调用真实/外部模型或付费服务；不得重启已有服务或运行 `next build`。
