# 更新日志

## 0.2.0

- 新增 `/error-retry import <文件路径>` 和 `/error-retry export <文件路径>`。
- 兼容 DSH v1 规则文件、原生配置对象和裸规则数组；导出文件可直接导入 DSH。
- 导入先校验、确认后替换，并保留配置冲突和会话生命周期保护。
- 导出原子创建新文件，不覆盖已有目标；支持默认规则导出、1 MiB 大小限制和失败清理。
- 源码改由 `librola/pi-extensions-shuyuan` 统一管理，npm 包名保持 `pi-error-retry`。

## 0.1.0

- 按规则无限重试匹配的模型错误，并在输出长度截断后自动续写。
- 提供规则编辑、热更新、配置冲突校验和标准停止行为。
